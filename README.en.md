# 基于ESP32的彩屏XT60功率计or电流表

#### Description
XT60接口的电压电流功率表，量程60V/30A，LCD彩屏，20bit ADC（ADX122AMSOP10），LCD屏幕可显示电压电流波形，带电池，外接供电/电池供电，可充电，USB串口打印采样数据，上位机vofa可显示波形，ESP32S3主控
