01背景、问题与目标

1.1 观察到的问题

证据（2026-10 代码实证 + 两份历史审计交叉核对）： ① 4kHz DMA 采样重构处于 WIP 中间态——数据引擎已落地并接线，但控制面容错只完成约一半、全量验收完全未做； ② 两个在途缺陷（波形规律性尖峰、引擎启动链超时）排查未闭环，取证探针留在生产代码路径，其中自动模拟按键翻页会篡改开机行为； ③ 电压/电流换算增益仍是未实测的理论值，仪器「读数可信」无数据背书； ④ 数据出口（导出 / 远程读数 / 升级）全部缺失——用户无法把测量数据带走，设备无法远程升级。

受影响的用户与时刻：把设备当作直流功率测量仪器的使用者（电池 / 电源 / 负载测试场景）。在「读数要拿去做决策」的时刻（标定、对比、留档），现有产品既不能证明读数精度，也不能把数据导出留档。

产品决策：放弃「堆功能」路线，按 质量收口 → 仪器可信 → 数据自由 → 社区化 的顺序分四个门控阶段交付；每阶段以可二值验证的验收收口，前一阶段验收不通过不开下一阶段的功能开发。

预期可观测结果：使用者在 v0.2.0 后可以相信屏幕上/导出数据的数值误差在标定阈值内且有实测记录；在 v0.5.0 后可以把数据以 CSV 带走、在网页上实时读数并远程升级固件；在 v1.0.0 后可以把设备接入家庭/实验室自动化体系。

1.2 目标

  • 读数可信：完成真机标定并公布实测精度（目标 ≤±0.5%，不达标则公布实测值），测量链路通过 24 小时长跑验收。
  • 行为可信：出厂固件不携带任何调试行为；掉电 / 崩溃 / 升级失败均可恢复，不出现「不可救回」状态。
  • 数据自由：测量数据可导出（CSV）、可远程读取（网页）、固件可远程升级（A/B 回滚）。
  • 覆盖完整：纯按键与触屏双路径全功能可达；数值、单位、持久化行为在掉电重启后保持一致。

02产品契约与核心模型

产品契约

使用者：需要直流电压/电流/功率/电能测量与留档的工程师、爱好者。

触发：XT60 接入被测电源/负载，设备上电。

核心任务：读到可信的测量值，观察波形，必要时告警保护、导出数据、升级固件。

完成条件：测量值稳定显示且与参考仪表一致（标定阈值内）；需要留档时数据可导出且与屏显一致。

可信基础：启动自检 + 分级故障指示 + 崩溃取证 + 掉电恢复。

核心对象（单一定义）

测量快照：电压/电流/功率/电能/Ah/峰值 的当前值集合，掉电可恢复的部分持久化。

标定参数：电压、电流的增益与零偏，经真机标定写入。

告警规则：阈值 + 触发状态 + 响应动作（蜂鸣 / 弹窗）。

用户设置：显示、声音、方向、告警阈值等偏好，掉电保留。

固件镜像：带版本与签名的可升级单元，双份互为回滚。

2.1 系统状态模型（已有，本期不变）

INIT启动未完成 · 指示灯常亮
→
RUNNING无故障 · 慢闪
→
DEGRADED非致命故障 · 双闪，静音
→
FAULT致命故障 · 快闪 + 每秒长鸣，不复位

致命故障 = 测量前端（ADC）或基础设施故障；其余外设故障只降级。本期仅扩展故障位来源（告警不进入该状态机，见 §6）。

03范围（P0 / P1 / 排除项）

3.1 P0：最小完整旅程

「接入 → 读到可信数值 → 异常时被告警 → 数据可留档」：

  1. 进入：上电自检通过（或降级提示明确），测量页显示 V / I / P / Wh。
  2. 完成：数值与参考仪表一致（标定阈值内，有实测记录）；峰值 / Ah 可查且掉电保留。
  3. 保护：越阈值 200ms 内蜂鸣 + 弹窗，用户可调阈值。
  4. 恢复：掉电重启后电能 / Ah / 峰值 / 设置不丢；固件异常可经 coredump 取证；升级失败自动回滚。

3.2 P1：支撑能力

  • 波形 120s 时间窗可用（无空白槽、包络正确）；自动息屏 / 锁屏；温度补偿；恢复出厂设置。
  • WiFi 配网、Web 实时读数、CSV 导出、OTA 升级（v0.5.0）。
  • MQTT/Home Assistant、多语言、成本报表（v1.0.0）。

3.3 明确排除（防止分歧）

排除项原因
触发捕获（超阈值冻结波形）、统计面板、校准参数导入导出本轮评审明确暂缓；保留在 backlog，不进入任何阶段承诺。
USB PD 解码、蓝牙 App、云账号沿用既有不做清单；蓝牙与「无手机依赖」的配网原则冲突。
交流测量 / 真有效值（RMS）档现有前端为直流口径（块均值）；RMS 留给未来交流档，本期只统一文案口径。

FR-MEAS测量与读数可信（含峰值 / Ah）v0.2.0

目的：让「屏幕上显示的数」和「拿去用的数」都有精度背书。

ID用户与触发产品行为规则与状态
FR-MEAS-01 维护者完成真机标定（接参考仪表） 按 ≥5 个标定点（0 / 10 / 25 / 50 / 75 / 100% 量程）写入增益与零偏，生成标定记录 记录含每点标称值 / 实测值 / 误差；误差 ≤±0.5%（≥10% FS 读数）为合格，不合格则记录实测精度并注明原因；标定值掉电不丢
FR-MEAS-02 使用者观察测量页 显示电压 / 电流 / 功率 / 电能（Wh）/ 累计容量（Ah）/ 运行时间 直流口径为块均值（非 RMS，见 §6 口径规则）；单位 V / A / W / Wh / Ah；数值稳定显示不跳字
FR-MEAS-03 使用者查看峰值统计 显示电压 / 电流 / 功率的本次上电最大 / 最小值 峰值随测量持续更新；掉电后恢复上次持久化值（与电能同一持久化节奏）；提供清零入口（需确认，见 §6）
FR-MEAS-04 掉电重启后 电能、Ah、运行时间、峰值从持久化恢复并继续累计 恢复值不得因精度回退导致「累计停滞」（超 1024Wh 后增量必须继续生效）

例外：ADC 故障时测量值冻结并进入 FAULT 提示；标定参数损坏时回退出厂默认值并在「关于」页标注未经标定。

FR-ALM告警保护v0.2.0

目的：过压 / 过流 / 过功率时第一时间提醒使用者，避免被测件与测量装置受损。

ID用户与触发产品行为规则与状态
FR-ALM-01 使用者在设置页配置阈值（过压 V / 过流 A / 过功率 W） 阈值可设 / 可关（每项独立使能），保存后掉电保留 阈值范围 0～满量程；使能关闭的项不参与判定；非法输入（超范围 / 非数）拒绝并保持原值
FR-ALM-02 测量值越过已使能阈值 蜂鸣告警 + 弹窗显示越限项与当前值 自采样块判定越限起至蜂鸣发声 <200ms；弹窗渲染允许 +100ms；持续越限按告警周期重复鸣响（沿用既有报警节奏配置）
FR-ALM-03 测量值回落到阈值内 告警停止，弹窗保留「已恢复」状态后自动关闭 回到正常不需重启设备；一次越限事件只产生一个告警弹窗（不堆叠）
FR-ALM-04 使用者在弹窗上确认 静音本次告警，弹窗关闭 确认只影响当前事件；下次越限重新告警；按键与触屏均可确认（纯按键可达）

例外：FAULT 状态下不重复弹告窗（先处理致命故障）；蜂鸣器故障时告警仅弹窗 + 指示灯。

06共享规则与例外

6.1 数值与单位口径（唯一定义）

  • 直流口径：块均值（约 200ms 窗口内的平均值），不称「真有效值 / RMS」；RMS 保留给未来交流档。所有界面文案与文档统一此口径。
  • 单位：V / A / W / Wh / Ah / ℃ / %RH；数值显示不跳字（末位稳定策略统一）。
  • 舍入：显示值按界面精度四舍五入；累计量（Wh / Ah / 费用）按内部高精度累计，仅显示时舍入。

6.2 持久化与掉电恢复（唯一定义）

  • 用户设置：改动后防抖落盘（停止操作约 1.5 秒后写入）；离开设置页 / 关机前立即落盘。
  • 累计量（电能 / Ah / 运行时间 / 峰值）：周期性落盘 + 启动恢复；恢复后继续累计，不得停滞。
  • 标定参数：单独保存，不随「恢复出厂设置」清除；损坏时回退出厂理论值并标注「未经标定」。
  • 存储寿命：任何高频数据（历史记录）不得直写配置存储，历史数据按限频写入数据分区。

6.3 确认与不可逆操作

操作确认方式可逆性
电能 / 峰值清零弹窗二次确认（触屏 + 按键双路径）不可逆，提示「无法恢复」
恢复出厂设置弹窗列出将被清除的项不可逆；标定保留
忘记 WiFi 网络弹窗二次确认可重新配网
固件升级版本确认后执行失败自动回滚（FR-OTA-02）
清除历史数据弹窗二次确认不可逆，导出建议先行

6.4 隔离原则（跨模块约束）

  • 测量与联网隔离：联网 / 网页 / 升级的任何负载不得影响测量数值与采样时序；联网故障只降级不进 FAULT。
  • 告警独立于故障状态机：越限告警是业务事件（蜂鸣 / 弹窗），不改变系统状态机的 INIT/RUNNING/DEGRADED/FAULT。
  • 按键与触屏等价：所有 P0 流程（含弹窗确认）纯按键可达。
