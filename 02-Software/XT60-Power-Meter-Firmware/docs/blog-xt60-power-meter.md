# 【开源】XT60 功率计：基于 ESP32-S3 的 24bit 彩屏直流电压电流功率表（0~90V / 75A 峰值）

**开源一个能直接插进 XT60 回路的直流功率计：ESP32-S3 主控，TI ADS131M02 24bit 双通道同步采样（4kSPS），1mΩ 四端开尔文分流器 + 101:1 精密分压，测量 0~90V、额定 ±30A（峰值 ±75A）。1.83 寸 IPS 触控彩屏跑 LVGL 9，带示波器风格波形页；WiFi 连上路由器后可以用浏览器打开网页控制台看数据、看波形、改设置、导 CSV。硬件、固件、外壳、生产文件全部开源。**

做航模、无人机、电池充放电测试的时候，经常需要一台能直接串在回路里的功率计。要看得清大电流下的电压跌落，要抓得住插拔瞬间的浪涌，最好还能把数据同步到电脑。市面上能买到的产品，要么屏幕小，要么没有波形，要么数据只能自己看。于是就有了这个项目。

| 通信 | WiFi 2.4GHz，STA/AP，HTTP + WebSocket |
| 供电 | XT60 输入 / USB-C / 单节锂电池三路供电，TPS2116 优先 USB，TP4057 以 400mA 充电 |
| 自身功耗 | 约 0.7W |
| 外壳 | 上盖 / 中框 / 底盖三件式 3D 打印，SolidWorks 源文件 + 3MF |
| 固件 | v0.6.9，ESP-IDF v6.1 + LVGL 9.6 |

先说几个容易被误读的点：

- **±75A 是 ADC 满量程，不是可持续电流。** 1mΩ 分流器额定到 70A（70A 时压降 70mV、功耗 4.9W），但 XT60 接口只到 30A（30A 时压降 30mV、功耗 0.9W）。所以整机额定写 ±30A，想长期跑更大电流得自己改底板换 XT90。
- **90V 也不是分压链路的极限。** 分压本身能到 ±121V，是辅助电源（XT60 取电那路 Buck）最高输入 100V 把整机卡在了 90V。
- **电流小于 2mA 时显示 0 是正常的。** 1mΩ 分流器的小信号噪声不小（单帧 σ≈2mA），固件用 200ms 块均值加 2mA 死区压住空载跳动；波形页用的是原始样本，mA 级变化照样能看。
- **这不是计量器具。** 爱好者测量和调试够用，别拿去当标准表。

### 系统框架

![XT60 功率计硬件系统框架图](https://tc2.zeruns.com/Pic/2026/11/block-diagram_4e1dbc1b78441e2d29679fb0b7d7bc6f.webp)

### 电压采样

![电压采样原理图](https://tc2.zeruns.com/Pic/2026/11/image-20261106222831117_acf0e4e363f391a0d4f6b7ba33af24c9.png)

电压通道用 **101:1 精密分压**（100kΩ / 1kΩ，±0.1% 薄膜电阻），分压后经零漂移运放 LRA8551A 缓冲，再进 ADS131M02 的 CH1（PGA 1x）。

分压链路本身理论满量程 ±121V，但整机辅助电源最高输入 100V，所以设计测量范围取 0~90V。按这个量程折算，单 LSB 约 14.5µV。

### 电流采样

![分流器与电流采样](https://tc2.zeruns.com/Pic/2026/11/image-20261106222918309_e099710a3e10ec60d1fa0de043bf32b6.png)

![电流采样原理图](https://tc2.zeruns.com/Pic/2026/11/image-20261106223640128_f7bae675cfd244da20d27731f7d01640.png)

电流通道是 **1mΩ / 5W 四端开尔文分流器**，电压引出点独立于大电流走线，避免铜箔电阻串进测量回路；信号经 RC 滤波后直接进 ADS131M02 的 CH0（PGA 16x）。

PGA 16x 下 ADC 满量程对应 ±75A 峰值，1 LSB≈8.94µA。

为什么选 1mΩ？要覆盖 ±75A 峰值和 30A 额定，又要把分流器自身发热压在 5W 以内，1mΩ 是这几个约束交叉出来的结果。代价就是小信号噪声偏大，靠固件的块均值和死区来补。

### 电源与电池管理

![电源管理原理图](https://tc2.zeruns.com/Pic/2026/11/Snipaste_2026-11-06_22-22-09_cc631dd51b0ae752e5db4439c9ec5341.webp)

- **XT60 取电**：SY8511BADC 降到 3.3V / 1A。
- **USB / 电池**：TLV62084 降到 3.3V / 2A。V2 板用 TPS2116 在 USB 和电池之间自动切换，优先 USB。
- **充电**：TP4057，400mA，单节锂电池。电池电压经 1:1 分压进 ESP32-S3 的 ADC，用来显示电量。
- V1 板还做过一版用分立 MOS 实现电源切换的方案，两版原理图都开源了。

### 测量链路

1. ADS131M02 每 250µs 拉一次 DRDY，SPI3 + GDMA 读完整 4 字帧：STATUS / CH0 / CH1 / CRC。DRDY 下降沿中断里直接启动传输，把读窗和采样相位锁死。
2. CRC-16/CCITT 校验通过后，按标定参数换算成电压、电流和瞬时功率。
3. 原始样本写进 PSRAM 的三级环形缓冲，波形页回看和降采样都从这里取。
4. 每 200ms 结算一次块均值、平均功率、峰谷值和告警，同时积分电能和容量。
5. 每 25ms 产出一帧 40Hz 快照，UI 和网页都只读快照，不直接碰测量数据。

**双核分工**：Core 1 跑采样和测量，Core 0 跑 LVGL 渲染、按键和 WiFi/HTTP 服务。为什么不把测量放 Core 0？WiFi 协议栈会周期性吃掉不少 CPU，和 4kHz 采样抢核会造成采样抖动，直接反映到读数上。仪器类固件用硬件资源换时序确定性，是常规做法。

### 网页控制台

![网页控制台实时数据页](https://tc2.zeruns.com/Pic/2026/11/Snipaste_2026-10-25_01-59-40_84cf88d80e3008780c243f9abd56fd26.webp)

网页是直接编进固件的，不依赖外部 CDN，断网也能打开。五个页签：实时数据 / 波形图 / 设置 / API / 日志。

### 工程化

- **双 OTA 分区 + 启动回滚**：`ota_update_start(url)` 拉取式升级写备用分区，启动失败自动退回旧版本。网页控制台目前还没做固件上传入口，救砖还是以 USB / 串口烧录为准。
- **coredump**：崩溃现场写到独立分区，方便事后导出分析。
- **PC 端 UI 模拟器**：`tools/ui_sim` 用同一份界面源码在 Windows 上渲染并批量截图，烧录前先跑一遍布局回归。
- **主机端单元测试**：纯逻辑部分（补码扩展、标定换算、电能积分、按键状态机、AHT20 CRC）不依赖硬件就能测。
- **字库子集化**：主界面用 GB2312 一级+二级 6763 字，两个字重约 4.2MB，放独立的 storage 分区；启动页另用一套约 197 字的极小子集直接编进 app，首帧就是完整中文。

顺带说个踩坑记录：启动页以前要等文件系统挂载、全量字库加载完才显示，屏幕点亮要 1.42s。把显示链路（LCD / 触摸 / LVGL / IMU / 方向）前移到第 9~13 步、`fs_storage` 后移之后，现在大约 1.09s 就亮屏了。

## 使用说明

![功率计接入测试回路](https://tc2.zeruns.com/Pic/2026/11/IMG_20261022_173809_56f7d3083d82ebe94c2d913f47a490ef.webp)

1. **接线**：XT60 输入端接电源或电池，输出端接负载，注意正负极。输入输出方向可以对调，反向电流会显示成负数。
2. **开机**：开关拨到 USB / 电池这档就能开机。要是切在 XT60 取电档，输入得给到 5V 以上才起得来。
3. **测量**：主界面看电压、电流、功率、电能。点一下底部电能行可以在 Wh 和 Ah 之间切。
4. **波形**：滑到波形页，上滑呼出快捷菜单，切时间窗和 V/I/P 模式。
5. **快速菜单**：测量页上滑或者长按 K2，能调刷新率、清电能统计（清之前会二次确认）。
6. **配网**：设置 → WiFi 与热点 → 搜索 WiFi → 输密码。也可以让它开热点，手机连上设备热点再进网页配网。
7. **网页**：配网成功后，同一局域网的手机或电脑访问设备 IP 就行。
8. **充电**：USB-C 接 5V，TP4057 以 400mA 充，状态栏能看到电量。

## 功耗与测试

整机自身功耗实测大约 **0.7W**。这是设备自己吃掉的功率，测量的时候会叠加在被测回路上，低功耗待测设备的测试要留意这个本底。

![功耗测试](https://tc2.zeruns.com/Pic/2026/11/IMG_20261025_011603_d3efead4ab87642a4cdedd20f82ab0e5.webp)

采样链路的验证集中在两件事上：一是连续采样的帧完整性，二是 DRDY 到 SPI 启动的时序稳定性。4kHz 档 250µs 的周期窗口很紧，一旦读帧跨越转换完成时刻，DRDY 就会被硬件抑制、频率直接掉下来。最后的做法是 20MHz SPI 缩短读窗，加 DRDY 中断里直启 GDMA 锁住相位，实测连续跑下来帧率稳定。

> 精度方面目前的校准手段是：空载时做电流零点自动归零，再用已知电压和标准表修正增益 / 零偏。没有做多点标定和长期漂移测试。所以本机定位是"调试工具"，不是"计量仪器"。想要更高精度的可以自己补标定点，设备端设置页和网页都能改增益和零偏。

## 复刻说明

1. **资料是一整套，别只下固件目录。** 原理图、立创 EDA 工程、Gerber、BOM、钢网、SolidWorks 外壳、3MF 都在同一个仓库里。

2. **打板建议板厚 1.2mm**，阻抗和层压按默认工艺就行。Gerber 在 `05-生产文件/01-PCB/`，钢网文件是顶层底层拼在一片上的，淘宝下单激光钢网就行。

3. **焊接走"钢网 + 加热台"路线**：钢网对位固定 → 刷锡膏 → 照交互式 BOM 放器件 → 加热台或热风枪回流 → 最后焊直插件。交互式 BOM 在浏览器里打开，点位号会高亮，找元件很省事。

4. **烧录有两种方式**。装了 ESP-IDF v6.1 就用脚本：

   ```powershell
   cd 02-Software/XT60-Power-Meter-Firmware
   .\build_fw.bat
   .\flash_fw.bat COM3
   ```

   不想装环境就用 Chrome / Edge 打开 **ESPConnect**，走 Web Serial 烧完整固件。

5. **固件是 5 个镜像，别只烧 app**。`idf.py flash` 会按 `flash_args` 自动处理；手工烧的话注意 `storage.bin` 在 `0x830000`，里面是全量中文字体。**改字库必须全量烧**，只走 OTA 会出现"升级成功但中文变方框"。

6. **校准顺序别搞反**：先空载做电流零点校准（设备端采样 3 秒块均值），再校准电压增益和零偏，最后串标准表校准电流。参数写 NVS，掉电和升级都保留。

7. **外壳建议用半透明材料打印**，屏幕和状态灯能透出光来，比实色好看不少。

## 目前存在的问题

**USB / 电池供电时，3.3V 会倒灌到 XT60 接口。**

具体路径是：3.3V 经 XT60 取电那路 Buck 芯片内部 MOS 的体二极管，再经供电控制 MOS（Q4）的体二极管，倒灌到 XT60 端子。所以即使 XT60 没接任何输入，测量界面也会显示 2.45V 左右（3.3V 减去两级体二极管压降）。

![倒灌路径说明](https://tc2.zeruns.com/Pic/2026/11/image-20261109013933541_f7bf345408e05552d5e0e115956b14c5.png)

三个解法，按改动量从小到大：

1. **不改电路，也不用 XT60 取电**：直接不焊 XT60 取电那部分 Buck，只用电池供电。
2. **只改一个器件**：在 Q4 后面再串一颗背对背 MOS，把体二极管通路断掉。这是下一版要改的地方。
3. **干脆不用电池 / USB**：开关切到 XT60 供电档，就没有倒灌路径了，但必须接着 XT60 才能开机。

另外几条已知限制：

- 切到 XT60 供电时，输入最低 5V 才能启动。
- 电流 |I| < 2mA 按 0 处理，这是设计行为不是故障。
- 网页控制台没有 OTA 上传入口，升级还得插线。
- 测量结果是直流口径的块均值，不是真有效值（RMS）。要测交流或纹波得另做。
